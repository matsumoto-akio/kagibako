## カギバコ v0.1.0

最初のリリースです。

**あなたのMacの中に、そのまま置かれているAPIキーを数えます。**

`.env` に書いた、`.zshrc` に書いた、設定ファイルに貼った ——
そういう「平文のままディスクに残っているAPIキー」が今いくつあるかを表示します。

### 使い方

1. 下の `Kagibako-0.1.0.dmg` をダウンロード
2. 開いて「カギバコ」をアプリケーションフォルダにドラッグ
3. 起動して「このMacを調べる」を押す

1〜3分で終わります。

### 数え方

`grep` で探すと、テスト用のダミーキーやドキュメントの見本まで混ざって、
出てきた数字が使えません。カギバコは結果を3段階に分けます。

- **本物の可能性が高い** —— 画面トップの数字はこれだけです
- テスト用・サンプルの可能性が高い —— 参考として下に畳んで表示
- 誤検出の可能性が高い(変数名からの推定のみ) —— 同上

テスト用を除外ではなく分離にしているのは、テストのフォルダに本物のキーが
置かれている事故が実在するためです。見なかったことにはしません。

### 並べ方

「本物」の中も、同じ重さではありません。置かれている場所の性格で3層に分けます。

- **いますぐ対処** —— シェル設定(`.zshrc` など)、`~/.codex/shell_snapshots/`、
  ツールのグローバル設定。全シェルに読み込まれる、あるいは知らないうちに複製が増える場所です
- 確認した方がいい —— ホームや Documents 直下の `.env`、`token.json` などの認証ファイル
- そのままでよい可能性が高い —— プロジェクトフォルダ配下の `.env`

画面トップの大きな数字は「いますぐ対処」の件数です。総件数は小さく併記します。

### このアプリがしないこと

- **外部に一切送信しません。** 通信そのものをしません。
- **キーの中身は表示しません。** 先頭7文字と文字数だけです(`sk-ant-****(108文字)`)。
  結果の画面をそのまま人に見せても安全です。
- **ファイルを勝手に書き換えません。** 対処は手順を見せるところまでで、
  あなたの `.zshrc` や `.env` をアプリが編集することはありません。
  例外は再生成されるキャッシュ(`~/.codex/shell_snapshots/`)だけで、
  ここはボタンでゴミ箱に移せます。

### 見つけた後にやること

APIキー(AIを使うための、あなた専用の合鍵)は、あなたのクレジットカードの番号みたいなものです。
他の人に見られると、勝手にAIを使われて、その料金があなたに請求されます。

27件あっても、対処のパターンは場所の種類ぶんしかありません。やることは3つです。

1. スナップショットを捨てる
2. `.zshrc` から `export` を消してキーチェーンに移す
3. プロジェクトの `.env` は `.gitignore` に入っているか確認する

アプリはファイルごとに、その場所に応じた「なぜ危ないか」と手順を表示します。
手順はかんたんな方から並びます。最初に確認するのは、**そのファイルがどのツールのものか**です。
Claude Code や Codex のように公式のログインがあるツールなら、キーを消してログインし直すだけで済みます。
そうでないツールは、キーを消すと動かなくなるため、分からない場合は消さないよう案内します。
ファイルを編集させる手順の前には、必ずバックアップの案内を入れています。
キーチェーンへ移す場合も、「キーチェーンアクセス」アプリでの操作手順を先に出します。
ターミナルのコマンドは「詳しい人向け」として折りたたんであり、コピーできるだけで、実行はしません。

専門用語はそのまま残し、初出のところに短い注釈を添えています
(あとからご自身で調べられるようにするためです)。

キーを作り直すときは、この順番で行ってください。

1. 新しいキーを発行する
2. 使っている場所を全部、新しいキーに差し替える
3. 最後に、古いキーを失効させる

※ 先に古いキーを止めると、動いているものが止まります。

**キーは、誰にも見せないでください。**
配信やスクリーンショットに写り込むこと、GitHubに上げてしまうことが、一番多い漏れ方です。

**このアプリができるのは、場所を教えるところまでです。**
全部を一度に直す必要はありません。まず「いますぐ対処」の分だけで、リスクの大半は減ります。

### 正直に書いておくこと

これは「絶対に漏れなくなる」魔法ではありません。
ディスク上に平文で置きっぱなしにするのをやめる、そのための棚卸しの道具です。
詳しくは README をご覧ください。

### 動作環境

macOS 13 以降

デスクトップ・書類・ダウンロードの中まで調べるには、初回起動時の確認ダイアログで
許可してください。許可しなくても動きます(読めなかった件数として表示されます)。

Apple の公証(notarization)済みです。
